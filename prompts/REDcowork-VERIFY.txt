代码
运行 npm test、npm run check:runtime、npm run build，报告结果。确认浏览器产物（dist/client）里没有任何 API key、提示词或 guard_sdk 调用。

找那一餐（真实模型）
1. 标签为“✦ AI 检索”。等待时显示“AI 正在理解你的描述…”和取消按钮，没有假进度条。
2. DATA-MODEL.txt 第四节每条查询：记录实际结果、AI 理由、用时，是否符合预期。
3. 每条结果的“看原帖原文”必须是原帖逐字内容；AI 理由只复述原帖事实。
4. 同一家店的多条记录合成一张卡片；在家做的饭显示“在家做的 · 不显示地点”。
5. 卡片 → 查看原帖 → 查看餐厅 → 收藏，关闭后回到原查询；收藏状态在个人页一致。
6. 范围：“朋友”不含自己的记录；“自己”只含本人（含私密）；他人私密、隐藏好友、未接受的申请、朋友的朋友都不出现。
7. 快速连续改词、切换范围、取消：旧结果不能覆盖新查询。
8. 让模型不可用一次（例如临时断开 guard_sdk 或模拟超时）：界面提示并提供“改用关键词检索”，结果标“仅关键词匹配，未使用 AI”。

其余页面
