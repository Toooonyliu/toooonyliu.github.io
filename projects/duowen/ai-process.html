Designing Duowen with AI

The coding agents helped me get from an idea to something I could use. Using it made the next design decisions clearer.

Discover & Define

Start with a task I actually do.

I reflected on Flighty and Mibly, where I had to connect design decisions to evidence. AI helped me compare transcription tools and simulate possible workflows. The simulations were useful for generating questions. My own need to find and verify spoken feedback gave me the scope for this project.

Develop

Build alternatives I can react to.

I explored a library, a focus workspace, and a batch notebook. The early transcript read like a list of controls. I asked Claude to study the low-friction feel of Wispr Flow, then used the prototype to decide what to keep. I wanted a document I could read, with playback and correction available right where I needed them.

I tried WhisperX during development and shipped the web prototype with Deepgram Nova-3. The model supplies the words, timings, and speaker groups. I designed the ways to review and correct that output.

Deliver

Make the handoff visible.

When I mapped how I would compare several sessions, the goal became clearer. I needed to carry the recordings into the same analysis. I asked Claude to build Projects. In the next round, I asked Codex to make Send to AI visible and separate the Markdown attachment from the prompt, so I could see which recordings were included and revise the task independently.

Codex checked the real download and clipboard, and I reviewed the local version before approving the Vercel release. I used Codex to check the UI at desktop and simulated phone widths. The ten-transcript test checked the export structure using synthetic material.

Reflection

Keep checking the source.

AI helped me compare options, build revisions, and test interactions. It could produce a polished prototype before the workflow made sense. I had to try the flow myself, notice the hidden action, and decide what the user should see first. Speech recognition can also misassign a speaker, which is why the original audio stays within reach.

My next test is to compare a set of real playtests in an AI chat and check whether each cited moment holds up against the audio.
