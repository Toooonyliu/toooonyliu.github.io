Mibly｜代码结构（纯前端）

src/
  App.tsx / main.tsx / styles.css / mobile/   原手机运行框架（check:runtime 保护）
  Prototype.tsx      主状态与五个入口：首页（地图/动态）、消息、记一餐、回忆、我的
  FriendsMap.tsx     朋友餐食地图：真实街道地图（realMap.ts，Leaflet + Esri 深灰底图），加载失败回退插画地图
  Messages.tsx       消息：互动 + 私信，私信可引用一顿饭；演示对话为虚构，对方不会自动回复
  SocialViews.tsx    回忆、我的
  data.ts            用户、餐厅目录、餐食种子数据（朋友记录带生活化留言）
  recall/
    RecallPanel.tsx  找那一餐界面：范围、模型状态、按餐厅聚合、朋友原话、错误与降级
    adapter.ts       加载浏览器端模型（同站文件）、显示进度、执行检索
    semantic.ts      向量相似度排序、阈值、证据选择
    embedder.ts      onnxruntime 推理封装（浏览器与 Node 测试共用）
    tokenizer.ts     bert-base-chinese WordPiece 分词
    engine.ts        关键词检索（降级用）、recallPlan 硬条件、validateModelResponse 校验
public/models/bge-small-zh-v1.5/   模型 model_int8.onnx 与词表 vocab.txt
site/                构建产物，REDcowork 上线的目录
tests/               recall-engine（22 项规则与校验）、recall-semantic（6 项真实模型）
scripts/semantic-calibrate.mjs   阈值校准

构建：npm ci → npm run build → site/。vite base 为 "./"，所有资源相对路径。
